# Топ‑5 современных одноэтажных домов

Лендинг застройщика (в духе referenced-страницы про топ‑5 одноэтажных домов) с
собственной админкой: управление контентом сайта, приём и обработка заявок —
без правки кода.

## Стек

- Node.js + Express
- EJS для шаблонов страниц
- express-session — вход в админку
- multer — загрузка изображений
- exceljs — выгрузка обращений в `.xlsx`
- Данные сайта хранятся в JSON-файлах внутри `src/data/`, картинки — в `public/uploads`

## Установка и запуск

```bash
npm install
npm start
```

Сайт: http://localhost:3000 (или порт из `.env`)
Админка: http://localhost:3000/admin

## Доступ в админку

При первом запуске логин и пароль берутся из `.env`:

```
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123
```

Дальше они хранятся отдельно, в `src/data/admin.json` (пароль — не в открытом
виде, а как соль+хэш), и их можно сменить прямо в админке: вкладка
**Настройки** → указываете новый логин/пароль и текущий пароль для подтверждения.
После первой смены значения в `.env` больше не используются.

**Обязательно смените пароль по умолчанию** перед тем как выкладывать сайт в
интернет. Файлы `.env`, `src/data/admin.json` и `src/data/leads.json`
(в нём реальные имена/телефоны/e-mail обратившихся) не должны попадать в
git — все уже добавлены в `.gitignore` и создаются пустыми автоматически
при первом запуске на новой машине.

## Что можно настроить в админке

- **Контент сайта** (вкладка «Контент сайта»):
  - главное изображение (hero-баннер);
  - карточки домов — добавление, редактирование и удаление. У каждого дома
    есть отдельная страница (`/houses/:id`) с фотогалереей, полным описанием
    и таблицей характеристик. В разделе «Проекты» можно выбрать этажность,
    фундамент, стены, кровлю, отделку, отопление и дополнительные опции.
    Блоки и варианты общие с подбором проектов и редактируются в его настройках.
    Площадь берётся из поля проекта, остальные характеристики (участок,
    спальни, санузлы и т.д.) задаются построчно;
  - подбор проекта (`/calculator`) — диапазон площади и фильтры по параметрам
    домов без расчёта стоимости. «Не важно» пропускает одиночный фильтр;
    дополнительные опции учитываются, только когда выбраны, и проект должен
    содержать все отмеченные опции. Результаты обновляются сразу; без JavaScript
    работает кнопка «Показать проекты». Выбранные параметры сохраняются в заявке;
  - фотогалерея дома — можно добавить сразу несколько фото и удалить любое
    по отдельности;
  - блок «5 причин выбрать одноэтажный дом» — текст и картинка каждого пункта;
  - контактная информация (телефон, e-mail, адрес).
- **Обращения** (вкладка «Обращения») — все заявки с формы на сайте:
  - статусы «Новая» (по умолчанию) / «Выполнена» / «Отклонена»;
  - комментарий/заметка к каждой заявке;
  - выгрузка всех обращений в Excel (`.xlsx`);
  - полное удаление заявки;
  - список автообновляется раз в 5 секунд (кроме момента, когда печатается
    комментарий, чтобы не потерять несохранённый текст).
- **Настройки** (вкладка «Настройки») — смена логина и пароля для входа в админку.

Изменения сохраняются сразу и применяются на сайте без перезапуска сервера.

## Структура проекта

```
server.js                 — точка входа
src/routes/public.js      — страницы сайта (включая /houses/:id), приём заявок
src/routes/admin.js       — вход, панель управления, обращения, настройки
src/middleware/auth.js    — проверка, что админ залогинен
src/data/content.json     — тексты и пути к картинкам сайта
src/data/store.js         — чтение/запись content.json
src/data/leads.json       — список обращений (заявок с сайта)
src/data/leadsStore.js    — чтение/запись leads.json
src/data/admin.json       — логин и хэш пароля администратора (создаётся при первом запуске)
src/data/adminStore.js    — чтение/запись/проверка admin.json
views/                    — HTML-шаблоны (EJS)
public/css/style.css      — стили
public/uploads/           — сюда сохраняются картинки, загруженные через админку
```

## Заметки по разработке

- Заявки с формы (`/request`) сохраняются в `src/data/leads.json` и сразу
  видны в разделе «Обращения» — при желании туда легко добавить отправку
  уведомления на почту или в CRM.
- Форма заявки принимает телефон и/или e-mail — обязательно хотя бы одно из
  двух полей (имя всегда обязательно). Телефон проверяется на соответствие
  российскому номеру (мобильный или городской, 11 цифр с кодом страны) и
  автоматически маскируется при вводе как `+7 (___) ___-__-__`; e-mail
  проверяется на корректный формат. Валидация двойная: на клиенте
  (`public/js/form-validation.js`, мгновенная подсказка/подсветка полей) и
  на сервере (`src/utils/validate.js`) — так форма защищена и при
  отключённом JS.
- Загружать можно jpg, png, webp, gif, svg — до 8 МБ на файл.
- Для запуска с автоперезагрузкой при правке кода: `npm run dev`.
